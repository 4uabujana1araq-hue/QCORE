# Q-CORE v3 Pro
Professional responsive PWA interface. Upload to GitHub Pages and install from a mobile browser.
This build provides account UI, dashboard, plans, deposit/withdraw request screens, ledger, rewards, support, notifications, security, profile, and transparency pages.
Financial settlement, real balances, KYC, 2FA server validation, blockchain confirmation and withdrawals require a secure production backend and appropriate authorization/licensing before real-money use.
